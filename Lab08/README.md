# DS605 Lab 8: Decision Trees and SVM

This repository contains my implementation and comparison of Decision Trees and Support Vector Machines for the DS605 Fundamentals of Machine Learning lab.

## Files
- `DS605_Lab8_Decision_Trees_SVM.ipynb` — implementation, visualizations, and model comparisons.
- `data_banknote_authentication.txt` — Banknote Authentication dataset.
- `plots/` — generated plots, if saved separately.
- `results.csv` — model comparison results, if exported.

## Requirements
Python, NumPy, Pandas, Matplotlib, and Scikit-learn.

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run the cells in order.

## Topics Covered
- Decision Tree implementation using Gini impurity and entropy.
- Linear SVM implementation using hinge loss and gradient descent.
- Decision boundaries and SVM margins.
- Linear, polynomial, and RBF kernel comparison.
- Model evaluation using accuracy, precision, recall, F1-score, and execution time.
